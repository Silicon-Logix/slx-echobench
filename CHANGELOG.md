# Changelog

## 0.1.0 — development preview

- Offline Godot desktop laboratory and private binary C++ demo core.
- Synthetic normal-beam acquisition, A/B/C scans, quality faults and calibration.
- Native Renode/ThreadX A/B processing of the same saved input and Verilator FIFO.
- Recording, replay, annotations, comparison and HTML/JSON/CSV reporting.
- Validated NDE 4.4 single-A-scan mapping with native-session roundtrip.
- Native desktop resizing, maximized/ultrawide layouts, adjustable DPI scale and
  physical-pixel 3D rendering; public services and contact page.
- Allowlisted public repository with pinned runtime installation and local/CI checks.

The physical model is simplified. Advanced UT, AI, real hardware, generic device
formats and customer integrations require dedicated development and validation.
