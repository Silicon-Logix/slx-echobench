# Security reporting

This repository distributes the current 0.1.0 development preview for evaluation.
It does not provide a production security-support or hardware-safety commitment.

For a suspected vulnerability, contact Silicon LogiX through
https://www.siliconlogix.it/contatti and request a private reporting channel before
sharing exploit details, sensitive files or customer data. Use private vulnerability
reporting on GitHub only if the repository owner has enabled it.

The app uses inherited local pipes and does not require a listening service,
telemetry or online registration. It accepts only the included demo firmware and
the documented bounded interchange mapping. File hashes detect accidental or
unexpected changes; this unsigned preview does not claim authenticated updates.

Do not open executable content or install updates obtained from an unverified
source. Preserve the supplied third-party notices and review the declared scope
before evaluating any customer integration.
